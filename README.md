# Tic-Tac-Toe Game

A simple and fun Tic-Tac-Toe game built to practice core programming and game logic concepts. This project features a clean interface and smooth gameplay, demonstrating basic front-end development and interactive game design using JavaScript.

---

## Project Description

This Tic-Tac-Toe Game is a classic two-player game where users take turns marking X and O on a 3×3 grid. The game automatically checks for winning conditions and displays the result when a player wins or when the match ends in a draw. The project focuses on implementing core programming logic, DOM manipulation, and user interaction.

---

## Features

- Two-player gameplay
- Real-time win detection
- Draw match detection
- Reset and replay functionality
- Simple and user-friendly interface

---

## Technologies Used

- HTML   
- CSS   
- JavaScript  

---

## Learning Outcome

- Understanding game logic implementation
- Working with conditional statements and loops
- DOM manipulation using JavaScript
- Handling user events and interactions
